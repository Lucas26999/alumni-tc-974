# Delta

Panneau qui suit ta consommation Claude : avance ou retard sur la fenêtre 5h (le « delta »), barre 5h avec repère du temps écoulé, semaine, coût de session (estimation) et contexte utilisé.

## Installer

```
/plugin install delta --marketplace lucas26999/alumni-tc-974
```

Puis tape `/delta` pour afficher le panneau. Les chiffres 5h et semaine n'apparaissent qu'avec un abonnement et après une première réponse de Claude.
